# Discipline

Daily routine tracker, clean-streak counter and PG-leave alarm for Android.

- Tasks with timers, morning routine, sunscreen every 3 hours, evening study/freelancing plan
- Rings an alarm when you leave your saved PG/home location with compulsory tasks pending
- Reminder notifications at 6:00, 9:00, 12:00, 15:00, 18:00, 19:30, 21:00, 21:30, 23:00 (+ Wednesday shampoo)

The APK is built by GitHub Actions on every push — download it from the latest Release.
